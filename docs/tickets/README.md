## Quy ước file ticket
- Phần **Ticket** (tiếng Nhật, format Jira) = những gì ngoài đời ticket thật có.
- Phần **📚 Phần học** = giàn giáo học tập (D-008): khung sườn TODO, cú pháp, đối chiếu OutSystems.
- Phần **Lịch sử thay đổi** = mỗi lần TL sửa ticket ghi 1 dòng (ngày + lý do).
